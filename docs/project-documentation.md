# Web Application Project Documentation

## Project Overview

This project is a web-based application developed as a group project.

## Project Structure

- `Login/login` - User login interface
- `Sign-up/signup` - User registration interface
- `Main_Dashboard` - Main dashboard
- `images` - Project images and visual assets
- `docs` - Project documentation

## Technologies Used

- HTML
- CSS
- JavaScript
- Firebase

## Setup

1. Clone the repository.
2. Install the required dependencies.
3. Configure Firebase.
4. Open the application in the development environment.

## Testing

### Login
- Test valid credentials.
- Test invalid credentials.
- Test empty fields.

### Sign-up
- Test valid registration.
- Test missing required fields.
- Test invalid input.

### Dashboard
- Test navigation links.
- Test interactive elements.
